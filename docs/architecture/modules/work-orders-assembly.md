# Daijo MES: Work Orders & Assembly

## Overview
Work order dispatching, batch tracking, barcode generation, and packaging master/detail records.

**Models**:
- `App\Models\SpWorkOrder`
- `App\Models\AssemblyDailyProcess`

## Features
- Work order issuance and routing for assembly and sub-assembly processes.
- Batch tracking with printed barcode generation for serialized container boxes.
- Packaging master/detail records tracking packing materials and lot numbers.
